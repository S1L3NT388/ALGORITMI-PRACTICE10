# Реалізація двобічно зв'язного списку

Програма для практичної роботи №10: повнофункціональна реалізація структури даних «Двобічно зв'язний список» (Doubly Linked List) на базі зв'язаних вузлів із прямим та зворотним зв'язком.

## Що реалізовано

* **Архітектура вузлів:** клас `Node` (збереження значення `data` та покажчиків на `prev` і `next`) та керуючий клас `DoublyLinkedList` із посиланнями на `head` і `tail`.
* **Основні методи списку:**
  1. `add_first(data)` / `add_last(data)` — додавання елементів на початок та в кінець списку
  2. `remove_first()` / `remove_last()` — видалення крайових елементів
  3. `contains(data)` — перевірка наявності елемента в списку
  4. `get(index)` — отримання елемента за порядковим номером
  5. `insert(index, data)` / `remove_at(index)` — вставка та видалення вузла за довільним індексом
  6. `insert_range(index, elements)` — вставка масиву/множини значень за вказаним індексом
  7. `get_min()` / `get_max()` — пошук мінімального та максимального значень
  8. `get_size()` — поточна кількість вузлів у списку
  9. `display()` — форматоване виведення списку за шаблоном `{[index:0; value:10] ... [index:n; value:n]}`
